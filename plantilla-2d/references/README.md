# references/

Reels de otras cuentas que **tú** guardas a mano en `references/inbox/` para aprender del género (la fábrica nunca
descarga nada de nadie). `/referencias` los desmonta (`uv run reels ref <video>`) y deja lo aprendido en
`patterns.md` (mecanismos que funcionan) y `visto.md` (premisas muy vistas). Los vídeos nunca van a git. Se aprende
el mecanismo, nunca se copia el estilo: esta fábrica tiene el suyo (`docs/estilo.md`).
